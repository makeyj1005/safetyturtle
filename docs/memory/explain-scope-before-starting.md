긴 작업(노드 하나 만들기 등)을 시작할 때, 파일을 열기 전에 **전체 흐름에서 지금 어느
부분을 만드는지**를 먼저 한두 줄로 설명한다. 진행 중에도 오래 걸리면 무엇을 기다리는
중인지 알려준다.

**Why:** 2026-08-01 세션에서 `inspect_node` 를 만드는 동안 사용자가 두 번 끊고
"지금 뭐 하는 거야", "순찰 돌다가 소화기 점검하러 가는 그 파트 만드는 거야?" 라고
물었다. 코드와 검증은 정상이었지만 **어느 파트인지가 안 보였던 것**이 문제였다.

**How to apply:** "지금은 A → B → **C(여기)** → D 중 C 를 만든다" 식으로 위치를
먼저 찍고 시작한다. 검증 대기가 길어질 때는 무엇을 기다리는지와 예상 시간을 말한다.
[[patrol-progress-nav2]] 처럼 단계가 여러 개인 프로젝트에서 특히 그렇다.
